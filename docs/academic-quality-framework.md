# 优秀论文与论说文章的特征：学术审查协议 v2

整理日期：2026-09-27。

这份材料把代表性论文、原始方法学文献、期刊审稿要求与大学写作指南，转化为
本项目可执行的审查标准。它不是“读完所有优秀论文”的结论，也不是按引用数、
刊物声望筛选后得到的普遍规律。下列特征和操作性检查是本项目的综合设计，
来源提供依据，不能理解为每家机构共同认可了整个协议。

首先分清三个问题：**论证是否成立、文章贡献是什么、是否适合某个刊物**。
Nature 的录用标准包括新颖性、领域重要性与广泛兴趣；PLOS ONE 的有效性导向
允许重复研究与阴性结果。因此，投稿定位不能替代论证评价，缺少轰动性也不是
研究错误。[Nature 审稿标准](https://www.nature.com/nature/for-referees/policies-and-processes)、
[PLOS ONE 出版标准](https://journals.plos.org/plosone/s/criteria-for-publication)。

## 一、提取出的十二项核心特征

这些是正向目标。发现文章没有明显呈现某项特征后，仍须证明该项适用、全文未
提供答案，而且缺口确实影响本文，才能提出批评。不能直接把这张表反转成扣分表。

| 特征 | 审查者应具体追问什么 | 合格的批评须指出什么 |
| --- | --- | --- |
| 1. 问题清楚且值得回答 | 本文处理的困难、矛盾、未知或实践问题是什么？ | 问题与实际论证错位的位置；不能只说“意义不足” |
| 2. 贡献可辨认 | 相对已有认识，新增、修正、澄清或可靠确认了什么？ | 作者声称的增量与实际材料之间的差距；未经检索不能断言不新颖 |
| 3. 概念与范围可追踪 | 关键术语、对象、时间、量词是否在推理中发生变化？ | 未说明且改变结论的含义转换；合理定义调整和概念史变化不算偷换 |
| 4. 推理有根据 | 哪些材料或前提，经哪一步支持哪个结论？ | 最薄弱的具体依赖；重复结论、堆引文不能补上推理 |
| 5. 方法匹配问题 | 所选研究、选材或证明方法能回答该问题吗？ | 方法缺口为什么破坏本文推断；不要求作者改做另一类文章 |
| 6. 最强异议得到处理 | 有什么相关反例、竞争解释或规范异议会改变结论？ | 异议具体挑战哪一步，作者现有回应为何仍不足 |
| 7. 结论强度与证据相称 | 标题、摘要、结果和结论是否守住同样的范围？ | 跨段两端的原文；把假说、模型结果或相关性升级为已证实事实的步骤 |
| 8. 不确定性与边界诚实 | 哪些结果依赖假设、选择、噪声、解释分歧或未测条件？ | 足以改变判断的依赖；不能机械要求所有可能的稳健性检验 |
| 9. 复核路径适当 | 他人如何检查关键推导、材料解释或系统结果？ | 复核缺少的必要信息；公开、可运行、独立复现必须分开 |
| 10. 引用与综合忠实 | 来源是否存在、是否真支持主张、不同来源怎样合成？ | 具体来源及支持范围；引用多、来源有名或观点一致不等于论证成立 |
| 11. 结构服务理解 | 段落、图表和转折能让目标读者跟上论证吗？ | 读者在何处无法辨认主张、依据或关系；风格偏好不算错误 |
| 12. 归属与诚信透明 | 材料、他人成果、利益关系与适用伦理条件是否交代？ | 可见问题及待核实事实；不能由文风、缺少声明或异常数字推断造假 |

协议把这些特征分给三个既有审查维度：论证与反例、方法与可复核性、引用与证据。
一个审查者只处理本维度的问题，减少重复意见与跨维度指令冲突。

## 二、不同文章不能套同一份方法清单

| 文章实际任务 | 应重点核对 | 不应自动要求 |
| --- | --- | --- |
| 定量实证 | 选样与测量、识别条件、效应和区间、分析选择、结论边界 | 所有问题都用随机实验；只凭显著性决定有效性 |
| 质性与个案 | 材料到解释的过程、研究者立场、竞争读法、负面实例、方法适切性 | 统计代表性；所有流派统一采用饱和、成员核查或编码者一致性 |
| 人文、概念与规范论证 | 文本/版本/史料语境、概念区分、可恢复的价值前提与理由 | 实验、数据集、统计指标；所有分歧都必须有不同经验预测 |
| 形式理论 | 定义、假设、量词、推导、反例与现实适用条件 | 把直觉或有限案例当成一般证明；把纯理论改写为实验论文 |
| 系统性／叙述性综述 | 按自称类型核对选材、覆盖范围、来源冲突与综合推断 | 所有综述都需 PRISMA 图、穷尽检索或荟萃分析 |
| 工程、算法与系统 | 所声称性质、公平比较、数据隔离、资源条件与失败范围 | 所有文章都需消融、排行榜胜出、开源或覆盖全部部署场景 |
| 一般评论与政策议论 | 目标读者、问题、理由、事实归属、取舍与行动后果 | 学术新颖性、独立参考文献表或固定论文章节 |

“没有报告某个步骤”首先意味着不能判断；取得足以识别设计缺陷及其结论影响的
证据后，才能提出实质方法批评。设计也可能前后一致却不支持目标推断，不必先
找到内部矛盾。PRISMA 2020 本身明确不是方法质量评价工具；其完整性不能证明
综述实施正确。[PRISMA 2020 原始声明](https://link.springer.com/article/10.1186/s13643-021-01626-4)。

范围综述的偏倚或质量评估须按其目标与结论判断是否必要，不能只因采用系统检索
就强制要求；PRISMA-ScR 的相关项目附有条件。
[PRISMA-ScR 清单第 12、16 项](https://www.prisma-statement.org/s/PRISMA-ScR-Fillable-Checklist_11Sept2019.pdf)。

## 三、从具体论文提取论证动作

这里学习局部写作与论证动作，不把整篇名作认证为无缺陷，也不把小样本选文
当作“优秀论文总体”的统计样本。

**He、Zhang、Ren、Sun，Deep Residual Learning for Image Recognition（2015 预印本，
2016 CVPR）。** 第 1 节先把深度增加后的训练退化定位为具体问题，再提出残差
重参数化；第 4.2 节保留了 1202 层测试表现不及 110 层的结果及作者对过拟合的
解释。可提取的动作是：问题、方案和测试相互对应；保留不利结果；把观察与解释
分开。不能从这些例子推出“越深总是越好”，也不能把作者提出的解释当成已独立
验证的机制。[原文第 1、4.2 节](https://arxiv.org/html/1512.03385v1)。

**Ioannidis（2005）与 Goodman、Greenland（2007）的争论。** 原文以模型假设讨论
研究结果可信度；批评针对显著性处理、偏倚项及概率解释，作者回复则反驳若干归属
并进一步说明条件。可提取的动作是：把争论落到具体假设和推断对象；审查批评时
也核对作者回应。这里只呈现争点，不依据声望或评论数量裁决哪一方全部正确。
[原文](https://journals.plos.org/plosmedicine/article?id=10.1371/journal.pmed.0020124)、
[批评](https://journals.plos.org/plosmedicine/article?id=10.1371/journal.pmed.0040168)、
[作者回复](https://journals.plos.org/plosmedicine/article?id=10.1371/journal.pmed.0040215)。

## 四、来源与规则的对应

下面记录已核对的原始指南或官方说明及本项目的使用边界。运行时只把当前审查
维度需要的来源和条目放入协议；不把整份阅读材料重复塞进每次请求。

| 来源 | 本次吸收的内容与边界 |
| --- | --- |
| [Harvard：Asking Analytical Questions](https://writingcenter.fas.harvard.edu/asking-analytical-questions) | 从值得解释的问题出发，借证据、假设和逻辑推进思考；据此设计问题与贡献检查 |
| [PMLA：Author Instructions](https://www.cambridge.org/core/journals/pmla/information/author-instructions) | 按文章所属类型评价，关注问题、发现含义和可读性；投稿原创性要求不等于思想创新的充分证明 |
| [Harvard：A Guide to Writing in Ethical Reasoning 15](https://writingproject.fas.harvard.edu/file_url/156) | 印刷页 1–2、5 的公平重构与理由检验；批判可以支持原立场，不必以否定结束 |
| [UVA：Literary Analysis](https://writingcenter.virginia.edu/literary-analysis) | 可争辩的解释需要具体文本支持；转为材料、语境与解释桥梁检查 |
| [Harvard：Counterargument](https://writingcenter.fas.harvard.edu/counterargument) | 处理有分量的异议，必要时调整主张；不为形式完整编造反方 |
| [Harvard：Anatomy of a Body Paragraph](https://writingcenter.fas.harvard.edu/anatomy-body-paragraph) | 分论点、材料与分析帮助读者跟上论证；不强制每段采用同一排列 |
| [APA：Qualitative Psychology 投稿指南](https://www.apa.org/pubs/journals/qua/submit) | 方法、解释过程、反思性、材料依据和替代解释；使用一般而非僵硬标准 |
| [ASA：p 值声明官方摘要](https://www.amstat.org/asa/files/pdfs/p-valuestatement.pdf) | p 值不能替代效应大小、重要性或假说概率；据此限制阈值化批评 |
| [PRISMA 2020](https://link.springer.com/article/10.1186/s13643-021-01626-4) | 系统综述透明报告及其适用范围；明确区分报告和实施质量 |
| [Baethge 等：SANRA（2019）](https://link.springer.com/article/10.1186/s41073-019-0064-8) | 叙述综述的目的、选材说明、引用与推理；本项目不采用其总分，也不外推医学样本的阈值 |
| [NeurIPS：Paper Checklist](https://neurips.cc/public/guides/PaperChecklist) | 理论假设、实验说明和与贡献相称的复核路径；No/NA 或未开源通常不自动构成拒稿理由 |
| [ACM SIGSIM-PADS 2024：Artifact Evaluation](https://sigsim.acm.org/conf/pads/2024/blog/artifact-evaluation/) | 区分材料可获得、可运行、可复用及结果复现；这是具体会议实施说明，不宣称所有会刊要求相同 |
| [PLOS ONE：Criteria for Publication](https://journals.plos.org/plosone/s/criteria-for-publication) | 技术可靠、结论有据、表述可懂与诚信要求；不将影响力或新颖程度作为有效性的替代 |

补充阅读核验到摘要层面：[O’Brien 等，SRQR（2014）](https://pubmed.ncbi.nlm.nih.gov/24979285/)
强调透明度与方法多样性的兼容；[King（2021）](https://doi.org/10.1002/nur.22157)
讨论统一程序要求的局限。本次未取得这两篇全文，未把其中未读到的细节写成已核验
规则。代码中的具体质性要求以已读的 APA 指南为主。

## 五、如何写出“一针见血”的意见

输出依然使用已有 Finding 格式，不增加一个形式化大表要求模型反复填充。

1. `standard`：哪条标准，以及为什么适用于这篇文章。
2. `evidence` / `location`：原语言原文与真实段落；跨段问题保留两端。
3. `issue`：究竟哪个概念、步骤、比较或归属出了问题；分清错误、未交代与无法核验。
4. `consequence`：不修补会让哪个结论失效、收窄或变得不确定。
5. `check_data.close_reading`：作者实际立场、最强已有辩护、辩护后仍存的问题，以及修补验收方式。
6. `suggested_action`：最小充分修改；澄清或收窄足够时，不要求新增整项研究。

例如，不输出“样本太小，建议扩大样本”。先辨明该样本用于什么推断；若论文是
一个解释性个案，样本小本身不成立为批评。若全文确实把这一材料推广为总体比例，
才引用该外推句和材料说明，指出其间缺少的依据，并允许作者选择收窄结论或补充
相应证据。此例是设计示例，不是对真实稿件或模型能力的评测结果。

意见按核心结论受到的影响排列，同一缺陷多处出现合并呈现；不要求凑数。已经
有根据、回应充分的部分应保留。零 Finding 也只表示本次没有形成有根据的问题，
不表示全文得到正确性认证。

## 六、验证与版本边界

实现位于 `review_profiles.academic_protocol()`，协议版本为 2。原有 critic ID、
Finding 响应格式、细读字段与对抗深审响应版本保持兼容。新请求保存新协议快照；
旧请求、对抗深审及修订复查沿用各自原始快照，不能在软件升级后追溯套用新标准。
旧专业工作台的 Markdown lens 协议是独立入口，本次没有改写它们。
v2 是协议版本，本次交付为源码更新；已经下载的 0.2.20 便携包不会自动取得新协议。

自动测试验证类型路由、来源映射、对象隔离以及真实请求到复审的快照保留，
**不能证明这些标准提高了模型准确率**。质量验证仍需用未泄露答案的真实稿件，
比较误报、漏报、定位和批评的实质影响；测试夹具或本文示例不能冒充独立作者试用。

本次验证：70 项相关回归通过；最终适用性措辞修订后，16 项学术专项测试再次通过，
另有 6 项测试在隔离安装的 wheel 中通过。上述运行有重叠，不相加为独立测试总数。
测试覆盖 75 种维度、学科与类型组合；其中的响应是明确构造的流程夹具，没有调用
模型，不能作为语义审查成绩。日志保留于本机 `dist/academic-quality-v2-*.log`。

建议后续盲测至少包含以下成对情形；这些是待独立标注的设计用例，不是已运行的成绩：

| 对照 | 应提的问题 | 应保留的合理写法 |
| --- | --- | --- |
| 个案与外推 | 单一个案推出总体比例 | 明确只解释该个案及其条件 |
| 阴性结果 | 仅据不显著宣称两组等效 | 给出区间并承认精度不足 |
| 文学解释 | 无视反向段落且无法解释 | 正面讨论该段并给出有据的读法 |
| 规范分歧 | 偷换未说明的价值前提 | 明示取舍且承认合理异议 |
| 综述 | 自称系统覆盖却无法说明取舍 | 明确限域的叙述综述 |
| 工程改进 | 数据泄漏或不公平比较撑起提升 | 条件相称的比较并报告失败场景 |
| 来源归属 | 引文支持的是较窄的另一主张 | 正确保留原来源限定与转引关系 |
| 概念变化 | 未说明的同词异义改变推论 | 以历史语义变化本身为研究对象 |
