# 0.2.17 · HTML 列表语义与隐藏条目边界

此前 HTML 列表只保留是否有序，`start`、`value` 和 `reversed` 会丢失。条目中的
多个段落或嵌套列表后的续文还可能被当作新条目，规范化导出统一显示 `1.`。

现在提取阶段计算默认十进制编号、显式起号／跳号、倒序，以及 `type` 指定的大小写
字母与罗马数字标记。空条目占用序号；内层列表不消耗外层编号。IR 记录列表、条目、
父条目、深度、序号及续文属性，独立审查可以辨认哪些内容属于同一前提。Markdown
和规范化 Word 只在条目首段标记编号，保留首段原本是标题或引文的结构。

列表序号遵循 [HTML 列表属性与序号规则](https://html.spec.whatwg.org/multipage/grouping-content.html#the-ol-element)。
字母／罗马数字采用 [CSS Counter Styles 的标准表示和范围](https://www.w3.org/TR/css-counter-styles-3/#simple-numeric)，
罗马数字超出 1–3999 时回退十进制，非正数字母序号亦回退十进制。编号属性限制
为最多 64 位数字，避免将异常超长输入交给大整数转换。

隐藏列表项省略结束标签时，现在可以正确进入后续可见条目或列表外正文；隐藏模板
及嵌入对象的隔离边界仍然有效。`hidden`／内联 `display:none` 条目不占渲染序号；
`aria-hidden`／内联 `visibility:hidden` 条目仍占序号，但正文继续按现有策略省略。

这是静态提取，不执行 CSS 或脚本，不重建完整浏览器布局。自定义 CSS 计数器、
继承样式和原始缩进仍需核对；嵌套关系保留在 IR，规范化文本副本不还原原始版式。
表格内列表仍展开为单元格文本，并增加明确的编号／层级核对提示。

88 项针对性回归通过，包含 HTML、RTF、分隔文本、Markdown、实际 Word XML、
原稿编号、持久化审查输入、IR／协议边界和学术流程。新增 10 项测试覆盖本次行为，
含隐藏内容隔离与超长编号拒绝。产品仍为 experimental preview；工程测试不替代
真实作者试用或模型审查准确率评估。
