# 0.2.9 · 表格导入容量保护

CSV／TSV 的不规则行和 HTML 的跨行、跨列表格会补齐空白位置，形成用于预览和
审查定位的矩形表格。此前仅统计实际单元格与合并范围，未把矩形内部补齐的空白
纳入总量限制：一个很宽的行加许多很窄的行，可以从小文件扩展出过量内存分配。
多个表格分别保持在上限内，也可能使整个文档超限。

现在在每次扩展表格前检查完整矩形大小，同一文档所有表格合计最多 50,000 个
位置，空白位置与跨行、跨列范围均计入。原有行数、列数、文本块、重叠范围限制
仍然生效。超过容量会阻止解析并保留原文件及诊断，不会发布截断的结构化文档。

回归先确认原实现放过六个超限案例，再验证修复：宽行位于开头或结尾的 CSV／TSV、
稀疏跨行跨列 HTML、多表格累计、恰好到上限时的文字和定位，以及使用实际容量限制
导入超限 CSV 后原件、诊断和项目完整性均保留。

此版本不改动既有项目的审查结论或协议；产品继续保留 experimental preview 标识。
