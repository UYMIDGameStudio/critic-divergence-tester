# 0.2.16 · 原稿编号保留

文本与 Markdown 原稿中的 `3.`、`7)`、`012.` 等列表标记此前只留下「有序列表」
属性，规范化导出会将它们全部写成 `1.`。这会改变编号前提、跳号条目以及重新起号的含义。

现在 IR 的 `attrs.list_marker` 保留原始标记，独立审查与对抗复核的文档块输入可读取
该信息。Markdown 草稿与规范化 Word 采用同一校验规则，保留数字、结束标点及
`-`、`*`、`+` 项目符号。正文引文及原文字符定位保持原有含义；代码围栏中的例子
继续按字面内容处理，不重新解释为列表。

缺少标记的旧 IR 使用原有兼容回退，不修改历史审计文件或猜测丢失的编号。
畸形标记及与有序属性冲突的标记不会进入导出。这次不承诺重建 Word 原生自动编号、
嵌套缩进或完整 Markdown 版式，也不扩展参考文献真伪核验能力。

修复前基线完整回归共 731 项：728 项通过，3 项依环境条件跳过。修复后 42 项
针对性回归通过，覆盖八种语言文本的编号往返、实际 Word XML、审查输入、原文定位、
旧 IR 兼容及 IR／协议边界。产品仍为 experimental preview；这些工程测试不替代
真实作者试用或模型语义审查质量评估。
