# 0.2.23 修订复审的证据与定位

此前，外部复审中的“已解决／部分解决／仍存在”只需附理由和一段证据文字。
程序会核对新增问题的引句，却没有核对这些既有问题的复审证据。进入下一轮时，
未解决项还可能沿用旧段落的位置，或者在旧段落消失后挂到修订稿的第一段。

新请求保存修订复审证据协议 v1，并将它纳入提示词与请求摘要绑定。每条结论须
提供修订稿段落 ID 和原语言引句；程序检查段落归属、引句内容、数量与长度。
理由和证据说明仍是模型提出的解释，不能因为引句存在就认定推理或结论正确。
“无法判断”允许缺少引句，但必须说明缺少什么材料，不能强行给出解决结论。

复审页将解释文字与核对过的引句分别显示；证据链接打开当前修订稿的段落，
不会误跳到具有相同 ID 的旧稿。繁體中文／English 提示保留原语言引文，仍须
逐项人工决定。导入结果后可以继续导入新的复审；新结果需要重新作出人工决定。
结果按持久化顺序确定先后，系统时钟回退不会让新结果被旧结果遮住。

开始下一轮时，继承问题使用第一条已核对引句的位置及内容。旧稿的细读说明
保存为历史说明，不作为当前修订稿的细读依据。无法可靠定位的未解决项会提示
补充引句；程序不再把它自动挂到其他段落。导出的风险说明也保留这项阻碍。

旧版请求仍可导入原格式结果，缺少结构化引句时明确标为未核验，不修改历史
记录。它们也可以补充结构化引句；只有经核对的引句，或能唯一匹配修订稿的
旧版原文摘录，才可作为下一轮的位置依据。已生成修改稿、尚未完成外部复审时，
界面进度保持进行中。

首次生成新复审请求时，项目的可更新完整性索引同时升级到 v2，保留原有条目和
摘要链。旧程序不支持该索引，会阻止写入，不能绕过新协议导入缺少引句的结果。
旧程序可能显示完整性索引格式错误；应使用 0.2.23 或更新的兼容版本打开。
新版在完整验证通过后，只清除这一已知的旧版兼容性只读标记，不清除真实损坏
或其他只读原因。普通旧项目保持可读写；尚未生成新复审请求时不升级索引。

自动验证使用构造的流程夹具，检查伪造／过期引句、人工关联、无法判断、历史
兼容、跨轮定位、重新导入及双语页面。本版仍为 experimental preview；这些
检查证明软件行为，不证明模型的语义准确率或商业试用已完成。
