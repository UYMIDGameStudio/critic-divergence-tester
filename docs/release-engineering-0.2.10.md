# 0.2.10 · 导入与恢复的文件名保护

此前文书和旧学术入口会接受带冒号、Windows 设备保留名称等文件名，直到写入
或备份阶段才出现异常。现在共享纯字符串校验，在创建项目库或写入原件之前拒绝
路径分隔符、备用数据流语法、不受支持的字符、末尾空格／句点及设备名称。
不会自动改写原文件名；界面提供繁體中文／English 重命名提示，并保留文件选择。

保留名称检查也覆盖带扩展名、扩展名前空格以及 COM／LPT 的上标数字形式，
备份、恢复路径中的每一层目录使用相同设备名称规则。
依据见 [Microsoft 文件命名说明](https://learn.microsoft.com/windows/win32/fileio/naming-a-file)。
合法 Unicode 文件名保持原样；不对中文、德语、法语、日语、俄语、拉丁语字符
或 emoji 做转写。为使项目可在支持的平台间恢复，这些限制在所有平台一致生效。

验证：44 项文件名、项目生命周期、旧学术入口与多语言导入回归通过；真实浏览器
23 项语言与流程检查通过，包含两种界面语言下实际上传保留名称并收到 HTTP 400。
另验证合法多语言文件名及原始字节经过创建、备份、恢复后完全保留且完整性有效。
原实现的校验在 18 个不安全名称案例上未按预期拒绝；新增测试先复现再验证修复。

此版本仍为 experimental preview；此次修复不改变审查结论或人工决定。
