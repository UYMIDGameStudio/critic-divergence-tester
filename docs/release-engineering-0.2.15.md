# 0.2.15 · 规范化 Word 结构导出

此前规范化 Word 副本逐行处理 Markdown，表格会变成含竖线的普通段落，换行标记
也可能直接显示。现在正式导出直接使用已校验的结构化文档或已批准的结构化修订稿，
生成真正的 Word 表格、单元格换行、制表符和标题层级。

内容中的首尾空白与字面标签保留，代码示例不会再次解析成正文标题。Word 将 CRLF
或 LF 表示为标准行内换行；分页符使用页面换行。不支持的控制字符会被拒绝，避免
生成损坏的 XML。修订 Word 的审计关系同时引用已批准 Markdown 和结构化修订稿。

保留原 Word 格式的导出路径继续使用原有流程；此修复改善的是规范化副本与明确
标注的降级副本，不承诺恢复原图片、合并布局、页眉页脚或原生修订标记。

本机执行 100 项文书、Word、交付及内容保持回归；另用 LibreOffice 26.8.0 实际
打开生成的 DOCX 并转成 PDF，核对提取文字及渲染页面，确认表格、多行单元格、
中文和字面代码内容可读。该样本验证不替代不同 Office 版本与复杂版式验收。
产品仍为 experimental preview。
