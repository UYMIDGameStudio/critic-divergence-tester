# 0.2.14 · 多行表格导出与字面内容

CSV／Office 表格单元格可以包含换行。此前规范化 Markdown 直接写入这些换行，
会拆开表格，甚至把单元格内的 `#` 文本误读为新标题。现在使用行内换行表示，
CR 与 LF、首尾空格、制表符通过可恢复的表示保留，不增加表格的实际数据行。

导出先转义单元格中的 HTML 字样、实体符号、反引号、竖线和反斜线，随后添加
换行与空白表示；原始 `<br>` 字样不会变成真正换行，原始标签不会成为表格中的
活动 HTML。再次导入时恢复文字与换行，代码跨度中的文字保持字面形式。
解码仅处理所需转义，避免误删公式中的花括号、下标等反斜线。

回归从真实 CSV 解析起，经规范化 Markdown 再导入，比对每个单元格。覆盖混合
CRLF／LF、多行文本、类似标题的内容、空白单元格、HTML 标签、已有实体、反引号、
反斜线与竖线的组合，以及公式文本；继续执行 Word 导出和审查流程回归。

这只改善表格中的内容保持，不代表整个 Markdown 文档已被做 HTML 安全清洗，
也不是完整的 Markdown／数学排版实现。原件与既有审查记录不自动重写，产品仍为
experimental preview。
