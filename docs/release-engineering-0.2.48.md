# 0.2.48：HTML 链接声明与来源边界

合成 HTML 复现了正文、列表、表格标题和单元格四处链接目标全部丢失的问题：可见文字
进入 IR，但 `href` 不在其中。新的 `html-text-v2` 解析器将地址保存到块的
`attrs.hyperlink_references`，与 `block.text` 分开；CSV/TSV 与 RTF 的解析版本不变。

每个锚点有稳定的来源内标识。一个链接跨越多个块时，各块保留同一标识和自己的文字预览。
预览最多512个字符，并标记是否缩短，正文和目标不截断。地址是字符引用解码后的属性声明，
不是补全或规范化后的 URL。空 `href` 保留为空；无 `href` 的命名锚点不冒充链接。
独立表格标题即使没有数据行，也会保留为正文块。

重复 `href` 的各项声明全部保留并提示核对；嵌套、未闭合的锚点提示文字范围不确定。
静态隐藏内容和嵌入对象继续遵守原有读取边界。落在不可关联文本位置的链接保留为文档级
声明，不补造正文或引句，不能据此认定作者遗漏引用。

基准地址只保存声明与来源行。上传文件的网页来源未知，本实现不重建浏览器 DOM、不解析
最终地址、不读取目标，也不执行脚本。链接、基准和定位数量受上限约束，解析后的全部内容
继续受统一 IR JSON 大小预算限制；超限保留原件，不返回成功的部分 IR。

全文阅读支持查看与搜索各块的链接声明。基准和未关联声明集中显示一次，重复属性和空目标
有明确提示；所有地址转义为文字，不产生可执行或可跳转节点。繁中与英文提供相同信息。
审查、对抗深审和修订复审共用的位置协议收到 HTML 来源限制及基准声明，明确记录不等于
文献核实；修订稿中的记录仍属于历史来源，不能证明改后的文字仍保留原链接。

旧项目、原件和已保存请求不自动重写；另建项目重新导入才采用新解析器。规范化文本或
Word 副本不据这些声明重建可点击链接；完整原件仍保存在项目中。

验证覆盖段落/列表/表格、跨块链接、隐藏内容、缺省结束标签、重复与空属性、独立标题、
不能关联正文的声明、预览与数量边界、最终 IR 预算、八种语言和编码，以及已保存的学术
请求。浏览器核对双语小屏、文字转义、无外部请求、原件及正文不变。发行自检新增
`html-hyperlinks`，共39项。这些工程检查不代替模型准确率或真实作者试用。

参考 [HTML Standard：链接](https://html.spec.whatwg.org/multipage/links.html) 与
[base 元素](https://html.spec.whatwg.org/multipage/semantics.html#the-base-element)。这里只保留
声明及读取限制，不声称实现完整 HTML 浏览器解析规则。
