# 0.2.5 · Windows 路径别名与安装保护

0.2.4 远端安装验证中，Unicode 快捷方式问题已修复；剩余两项断言将
`RUNNER~1` 与 `runneradmin` 两种路径写法误认成不同位置。
这些断言改为检查操作系统确认的同一目录，仍核对实际启动位置、工作目录及备份目标。

沿此检查发现安装器本身也只用路径文字检查目录重叠。本机已复现：
安装目录用长路径、嵌套项目目录用短路径别名时，原保护错误地允许继续。
现在用只读取元数据的文件句柄解析已存在的祖先，再拼接尚未创建的目录，
让安装、项目、快捷方式三处目录在任何创建或删除前按真实位置比较。
原有链接路径拒绝与删除范围限制仍保留。

旧安装记录中的短路径及大小写差异可正常核对，不要求用户修改安装记录。
新增真实 8.3 别名回归覆盖：未创建目录的重叠拦截、短路径安装、旧记录重试、
不同大小写的长路径卸载及快捷方式清理；无 8.3 支持的文件系统明确跳过别名案例。

使用的系统接口见 [Microsoft GetFinalPathNameByHandleW](https://learn.microsoft.com/en-us/windows/win32/api/fileapi/nf-fileapi-getfinalpathnamebyhandlew)。

远端 Windows 全量回归在 15 分钟时仍持续通过新测试，随后被工作时限取消。
CI 工作时限调整为 30 分钟；没有删除、绕过或降低任何测试断言。
