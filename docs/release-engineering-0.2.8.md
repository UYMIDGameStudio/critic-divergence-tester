# 0.2.8 · 浏览器启动与双语维护提示

真实浏览器回归曾收到操作系统分配的 6669 端口，Chrome 因 `ERR_UNSAFE_PORT`
拒绝打开工作台。共享本机服务现在按 [Fetch 标准的端口阻止表](https://fetch.spec.whatwg.org/#port-blocking)
检查自动分配结果：关闭被阻止的套接字后重新申请，最多 32 次；只监听可用结果。
显式指定受阻端口会在创建套接字前报错；其他绑定错误原样报告并释放资源。
这一修复覆盖统一入口、文书、学术与旧工作台入口。

备份、恢复和删除错误现在提供繁體中文／English 提示。完整匹配的已知系统消息
使用对应翻译；含文件名或原文的未知诊断提供本地化处理说明，并逐字保留诊断。
页面将这些内容作为文字显示，诊断中的 HTML 无法生成元素或执行脚本。

验证包括 17 项 HTTP／端口安全测试、35 项本机服务与交付回归，以及完整的
7 组真实浏览器测试。语言测试共 21 项，其中新增双语无效备份恢复、翻译完整性、
含原文与 HTML 的未知诊断检查。端口回归注入受阻分配、连续失败与绑定异常，
检查重试边界和套接字释放；浏览器测试实际操作恢复界面。

产品仍为 experimental preview。此次改动改善启动可靠性和错误处理，不代表
模型审查准确率或八种语言的学术审查质量已获得独立验证。
