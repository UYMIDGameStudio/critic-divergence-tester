# 0.2.42：原文阅读与综评定位

## 实际问题

此前完整原文面板只在存在 Finding 时显示。识别确认后初始预览会收起，零 Finding 的
学术综评虽然保留引文，却无法直接回看全文；综评中的块编号也没有跳转链接。
这使正向评价、取舍建议和文章整体分析的证据核对不完整。

本版将原文阅读器独立于 Finding 数量。确认识别后即可阅读；没有问题列表时以可展开
面板提供，有问题列表时继续放在审查工作区。综评方案和各自选角度的引文可直接打开
当前稿件对应内容，不存在的块不生成空链接。

## 阅读与导航

标题导航仅采用已抽取的 heading，不按关键词猜测章节。保留已知层级，不补造缺失的
上级标题；同名标题以不同块标识定位。过长标题只缩短导航标签，完整标题和正文不截断。
来源页码来自现有位置记录，不声称是修改稿重新排版后的页数。

正文按当前 block_id 生成定位元素，不把历史父位置编号当作当前块标识。修改后审查
使用本轮有效 IR；未改写源文件、原 IR、引文或审查意见。

搜索、匹配数量与清除操作持续可用。工具栏固定在阅读面板顶部；选择标题或页码后收起
目录，并将目标放在工具栏下方，键盘焦点移到正文。普通片段导航保留浏览器历史，支持
前进、后退及重新加载后的定位；修订稿引文继续使用独立的修订稿入口。

完成识别后的流程入口可回到阅读器。零 Finding 时「人工裁决」阶段可定位文章综评或
空结果说明，不因没有问题卡而变成不可用。质量门、人工决定和修改批准要求没有改变。

## 阅读状态与隔离

展开状态与阅读面板滚动位置属于本机 UI 草稿，沿用按有效文档 SHA 隔离的现有机制。
只保存布尔值和显示滚动量，不把它们作为原稿坐标或修改锚点。收起面板时不以隐藏元素
的零滚动值覆盖原位置。切换语言、展开和重载恢复阅读状态，同时重新应用已保存搜索。

位置根据当前版面恢复并受滚动范围约束，不承诺窗口尺寸变化后仍精确对应同一字符。
显式片段跳转优先显示目标，必要时清除冲突查询；一般重载仍恢复已保存查询。新稿件或
后续审查不借用旧文档的查询和位置。阅读动作不进入 Finding、Action 或 Hunk。

## 验证

真实项目浏览器验收覆盖：零 Finding 的长文学术综评；重复标题、层级跳跃和八种语言；
可疑 HTML 标题的惰性显示；来源页码导航；搜索零结果、清除、语言切换、收起与重载；
片段、前进后退和工具栏遮挡；后续审查的当前稿件及旧文档草稿隔离。

读取前后逐字节比较源文件、原请求、模型结果、决定与 Revision 记录。零 Finding 正式
导出继续保留原综评，阅读不会替用户批准修改。已有细读、修订证据、PDF 换行及草稿
冲突流程继续回归，繁中与英文在桌面和320宽度验证。

新 source_reader.js 纳入统一资源清单、wheel 和便携包。继续执行34项安装运行时自检，
并核对发行包与源码中的界面和文档一致；交互行为另由真实浏览器验收。这一轮改善证据
阅读与操作流程，不作为模型准确率提高或真实作者商业试用完成的证明。
