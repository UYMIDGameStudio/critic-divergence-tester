# 0.2.46：Word 链接声明与审查边界

原先导入只标记部分段落含有超链接，未保存实际目标；脚注里的「见此处」会进入审查，
但背后的来源地址丢失。拥有的合成文件复现了正文、表格、页眉和脚注四处目标均未进入 IR。

新 DOCX 解析器 v6 在 `attrs.hyperlink_references` 中分别保存来源部件、关系编号、
链接文字预览、原始目标、目标模式、书签及目标位置声明。关系编号按所在部件解释，
正文和脚注即使使用相同编号，也不会串用地址。缺失、重复、错误类型及无效目标模式
明确记为未解析，不从显示文字或备用书签猜测目标。目标与书签分别保留，不拼接猜测 URL。

正文、表格单元格、页眉页脚及可读脚注/尾注都使用同一规则；属性和未展开的兼容分支
沿用正文的排除边界。链接文字预览最多512个字符，并显式记录是否缩短；正文不截断，
目标仍受统一 IR 大小预算限制。未求值的 Word 域会保留缓存文字并提示限制；当前不解析
`HYPERLINK` 域指令、不执行域，也不宣称覆盖这类链接目标。

全文阅读中的「原件链接声明」可展开和搜索。标签、地址和来源路径全部转义为文字，
包括网页、本地文件、网络位置和脚本协议；不会生成可执行或可跳转的链接。
繁中与英文均提供相同提示，长地址可以在窄屏换行。

审查协议收到声明与读取范围，明确「已记录」不等于已访问、可用、安全或文献已核实。
未知目标不能单独证明作者漏引。修订稿中的记录仍是历史原件声明，不能证明当前文字
还保留相同链接。现有链接段落的原生 Word 修改保护保留；其他安全修改不改写关系文件。
旧项目、既有请求及原件不自动重写，重新导入才使用新解析器。

远端上一版的实际安装测试在60秒时终止，而安装器允许单项操作180秒。对一个项目的
自检、升级检查和备份分别有截止时间；外层测试现在等候这些时间加上复制与回滚余量，
保留安装器本身的超时和失败断言。

验证包含部件隔离、书签、缺失/重复关系、危险地址、八种语言、域边界、长度预算和
原生导出；浏览器覆盖繁中桌面与英文320宽度、地址搜索、文字转义、无外部请求、
已保存学术请求与原件不变。发行自检新增 `docx-hyperlinks`，共38项。

参考：[Microsoft Open XML Hyperlink](https://learn.microsoft.com/en-us/dotnet/api/documentformat.openxml.wordprocessing.hyperlink?view=openxml-3.0.1)
定义关系指向与显示文字；[Microsoft Word HYPERLINK 域](https://support.microsoft.com/en-us/word/field-codes-hyperlink-field)
说明另一种以域指令保存目标的方式，作为当前读取边界的依据。这些工程验收不替代模型
准确率评测或外部作者试用。
