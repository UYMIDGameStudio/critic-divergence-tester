# 0.2.22 细读协议与历史回传

学术审查协议 v2 要求批评具体说明作者立场、最强已有辩护、仍然存在的缺陷和
修补验收方式。本版修复这些细读说明在历史任务中的验收依据：原先回传校验与
版本回执仍读取当前程序的细读模板；以后模板升级时，旧任务可能被新字段拒绝，
或者留下错误的版本记录。

现在初审、人工关联导入与修订后的外部复审，均从原任务的不可变提示词恢复
细读协议。新请求同时保存完整协议及摘要；已有请求可以从原提示词恢复。
复审继续核对原请求、原提示词和审查维度的绑定，不能借人工关联绕过验证。
已发布的细读 v1 字段独立固定，不随当前模板变化。

不支持的版本、缺失或不一致的快照、错误摘要会阻止导入。完整快照采用规范 JSON
比较，避免把布尔值 `true`、浮点数 `1.0` 和整数版本 `1` 当成同一份协议。
相关固定错误提供繁體中文与 English 提示；未知诊断保留原文，防止误译其内容。

真实早期任务可能没有细读协议。本版明确记录“未保存细读协议”，不补写虚构的
历史版本；如果回传仍提供细读说明，则按固定 v1 检查字段和原文引句。缺少细读
说明继续单独记录，不因兼容导入而宣称已完成细读。复审中的细读回执仅覆盖新增
意见，不把既有问题的处理状态当作新细读的证明。

验证覆盖旧请求、当前模板变化、继承审查轮次、外部复审、协议版本与摘要冲突，
以及繁中／英文的错误提示、原文保留和证据跳转。测试使用明示构造的流程夹具；
细读协议仍为 v1，学术质量协议仍为 v2，均不等于模型语义准确率已经得到验证。
本版仍为 experimental preview。
