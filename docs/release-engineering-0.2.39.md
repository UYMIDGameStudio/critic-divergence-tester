# 0.2.39：各审查阶段的证据上下文

## 覆盖整条审查流程

文章综评负责还原实际问题、意图贡献与论证路线，并按文章需要选择承重角度；结构、方向、
方法和特点仍只是起点。本版补齐其证据呈现基础：review_frame 和每个自选角度的引文，
细读的 context_evidence，对抗辩护与复核的 context_evidence，以及修订复审的
source_evidence，都可显示原文上下文及局部截取、重复出现等提示。

修复外部复审新 Finding 缺少修订稿入口的问题。它的主引文与原问题的修订证据分别呈现，
相应文本块进入修订稿原文面板。新 Finding 不再套用旧版 resolution 的未核验标签；
原本未经核验的历史 resolution 也不会被补成已经核验。

这不新增或升级语义裁决。问题设定、贡献、材料取舍、解释增量、反驳策略、读者效果等
开放角度继续由现有协议选择；字符出现只证明引文来源，不能证明判断成立或审查完整。

## 绑定各自的稿件

当前细读及综评使用当前审查 IR；外部复审使用该次 revision 的 IR。对抗审查从 session
绑定的 document_relative_path 读取 IR，核对完整文件 SHA-256 和 source SHA-256 后生成
预览。历史 session 保留历史上下文，当前稿件即使复用块标识，也不能替换其来源。

正式报告保留原 AuditRun，旧综评明确标为历史审查状态，不附当前稿件的上下文。只有当前
有效综评获得当前证据引用。模型原始响应、Finding、AuditRun 和已保存请求都不改写，
既有响应契约及引文匹配语义不变。

## 有界的派生数据

一次投影为同一绑定 IR 建立局部 QuoteReviewIndex；主引文优先，再计算次级引文。
每个索引默认最多计算512条不同的块/文字/引文组合，重复引用共用计算与目录项。
缓存不跨操作保留。当前与历史 session 使用独立预算键，历史记录不会耗尽当前记录的预算。

达到上限后返回 matched=null 与 projection-limited：明确表示该项未做上下文预览，
不能解释成匹配失败。已算出的预览仍可复用。每项预览继续遵守0.2.38的上下文长度与
匹配扫描上限，局部词语提示仍是有限启发式。

视图和新导出在 quote_contexts 中存放派生目录，以 quote_refs 或 context_quote_refs
对应原有证据数组；对抗 session 和 external_recheck 各带其独立目录。可用预览记录
document_id、block_id、原始块文字 SHA-256，以及 advisory_only=true、
semantic_accuracy=not-established。目录只用于辅助核对，不是自动修改锚点。

新上下文在网页中转义为文字，在 Markdown 上下文区使用缩进代码块。原始证据字段保留
原样；这里不声明既有 Markdown 报告的所有自由文本均已转换成惰性文本。

## 验证范围

真实持久化项目覆盖索引复用与容量边界、模型伪造提示无效、主引文与细读共用上下文、
零 Finding 的综评、综评替换后的历史标签、跨修订对抗历史，以及复审新问题的原文入口。
既有引文、细读、综评、对抗和复审测试继续验证旧契约与人工决定边界。

四条真实浏览器流程覆盖繁中/英文呈现、综合审查320至1440宽度、次级片段警告、原文跳转、
惰性 HTML、历史记录与重新导入。安装运行时自检增加 secondary-quotes，合计32项；
wheel 与 Windows 便携包须分别独立自检并核对发行文件摘要。

这些是程序、协议绑定和呈现检查，不是模型准确率评测，也不替代真实作者商业试用。
