# 0.2.26：工作台界面与阅读体验

本次以用户提供的 2026-09-27 设计研究中的 `design-tokens.css`、
`audit-checklist.md` 和阅读说明为参考，采用其中的任务层级、语义颜色、
中文排版、克制动效与键盘可访问性原则。参数按长时间阅读和审查操作调整，
并非复制品牌官网或直接套用宣传页字号。

## 界面变化

- 工作台、研究流程和专业三栏共用离线样式基础：冷白背景、白色内容区、
  深蓝主要操作。绿色表示正向状态，琥珀色表示注意事项，红色表示危险或错误。
  同级卡片使用细边线，阴影仅用于浮层。
- 首页并列呈现新稿导入与本机项目。格式说明按需展开；专业研究、环境检查与
  备份位于后续区域。退出按钮移至页首，保存及退出期间仍阻止重复操作。
- 审查步骤显示编号、完成标记和当前阶段；原文、引用、判断和操作有不同层次。
  引文跳转保留上下留白，不改变正文、引句、段落标识或原有 PDF 连续阅读逻辑。
- 输入框统一覆盖未显式声明类型的理由等字段。按钮与输入框至少 44 CSS px 高，
  长标题、文件名、哈希和英文按钮可换行；三栏在窄屏堆叠。
- 增加键盘跳转入口、可见焦点与强制颜色支持；按系统减少动态偏好关闭导航的
  平滑滚动。繁体中文与英文继续独立于原稿内容，选中文件及草稿跨语言保留。
- 所有资源随应用打包，不加载在线字体、图片或组件服务。

## 验证方式与边界

浏览器回归使用临时合成项目，不读取或修改用户稿件。检查导入、原文定位、
双语切换、草稿、裁决、修订、复审、导出、备份和恢复；另外覆盖首页、审查页、
研究页及专业弹窗的桌面、窄屏与文字放大场景，并保留截图。

可使用 `npm run test:browser` 执行浏览器检查；仅布局检查使用
`node scripts/browser_layout.cjs`。布局报告与截图写入 `dist/ui-style-0.2.26/`。
运行环境可通过 `STUDIO_PYTHON`、`STUDIO_BROWSER` 和 `PLAYWRIGHT_MODULE` 指定。

这些检查不等于完整无障碍认证，也不证明实际使用效率或审查准确率提升。
本版未改写已有审查协议和用户记录；作者对照试用仍未完成。

安装和回退见 [便携版说明](portable-guide.md)。
