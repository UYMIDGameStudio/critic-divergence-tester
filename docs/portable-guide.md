# 本地便携版 · 0.2.3

解压完整发行 ZIP，在包含 `DocumentReviewStudio.exe` 的目录中双击程序。
程序会打开本机浏览器页面；请保留同目录的 `_internal`、安装脚本与发行清单。
无需预先安装 Python。界面默认繁體中文，右上角可切换 English，并保存选择。
原文、文件名和已输入草稿不会随界面语言翻译。

便携包包含文本 PDF 解析组件与 PDFium 页面渲染组件。八种语言的文字和常用格式支持范围见
[文档使用说明](document-review-studio.md#formats-languages-and-extraction-limits)。
扫描 PDF 需要另外安装 Tesseract 及所选语言包；真正的旧二进制
Office/WPS 文件需要本机 LibreOffice。选择一个语言或文件扩展名不代表所需组件
已经安装，也不代表该语言的模型审查质量已经验证。

## 安装、升级与回退

可以直接使用解压目录，也可以在该目录运行 `安装或升级.ps1`，安装到当前用户的
`%LOCALAPPDATA%\Programs\DocumentReviewStudio\<版本>` 并创建开始菜单入口。
关闭正在运行的工作台后再升级。

安装器会检查发行清单的结构、完整文件集、摘要和路径，拒绝额外文件、文件缺失、
链接或损坏内容。程序先复制到安装盘内的暂存目录，复制后重新校验；随后从已验证
的暂存副本运行自检及项目兼容检查。通过后再发布版本目录、登记安装记录和更新
快捷方式。已安装的旧版本保留；同版本但内容不同的包会被拒绝，不能借相同版本号覆盖。

遇到自检、备份或安装失败时，按报错处理后重跑安装脚本。正常失败会撤回本次
程序变更；进程被中断后，下次安装会检查并清理可验证的本次暂存记录。安装锁防止
两个安装器同时修改程序目录。若提示恢复记录或安装清单损坏，请保留目录处理，
不要手工改清单、删锁文件或把其他文件放进已登记版本目录。

**自动兼容检查及升级前备份有明确范围**：默认仅覆盖
`%LOCALAPPDATA%\DocumentReviewStudio\projects` 直属的
`*.document-review-studio` 项目，备份写入该库的 `backups` 目录。
旧 `.argument-workbench` 研究项目、其他命名项目及其他自定义库不在自动备份范围内。
升级前应另外备份这些项目；旧研究项目应在关闭工作台后复制整个项目目录到独立位置。

需要指定检查范围或做隔离部署时，可使用下列参数。三个目录应彼此分离：

```powershell
.\安装或升级.ps1 -InstallRoot 'D:\ReviewProgram' `
  -ProjectRoot 'D:\ReviewLibrary' -ShortcutRoot 'D:\ReviewShortcuts'
```

`-ProjectRoot` 指定安装前检查和备份的库，不会改变开始菜单快捷方式的默认项目库。
启动自定义库仍需显式传入：

```powershell
.\DocumentReviewStudio.exe app --data-dir 'D:\ReviewLibrary'
```

0.2.3 保留现有项目 schema，不自动重写旧审计产物；对抗深审记录有独立协议与校验。
遇到不支持的项目格式会拒绝打开。
升级后需要回退时，启动保留的旧程序版本，并将升级前备份恢复到独立项目库。
不要让旧程序继续修改已经由新版增加了新功能记录的项目。

## 备份与恢复

文书项目页面点击“備份目前專案 / Back up this project”，界面会显示备份保存位置。
首页选择备份 ZIP 并恢复；
现有项目不会被覆盖。超过浏览器上传上限的备份可在终端使用：

```
DocumentReviewStudio.exe studio-manage restore backup.zip D:\Documents\ReviewLibrary
DocumentReviewStudio.exe studio-manage verify D:\Documents\ReviewLibrary\项目.document-review-studio
```

备份含原稿、审查、人工决定及草稿等本地材料，请按文档自身要求保管。摘要校验用于
发现文件不一致，不是发布者签名或对抗完整磁盘写入者的认证机制。

## 导出与修改范围

Word 净稿优先保留原文档包，支持普通段落、连续段落和简单表格单元格的已批准修改。
在保格式路径成功时，未修改的包内样式、媒体、页眉页脚保持原始字节。
受支持的段内替换还提供独立原生修订副本。
修改位置含域、脚注、超链接、书签、复杂单元格或已有修订时，输出说明会明确指出
保格式处理失败及规范化副本的局限。此时文件明确命名为 `规范化修改稿.docx`
或 `规范化本轮未修改稿.docx`，并附 `Word导出说明.md`；规范化副本可能不含原图、
页眉页脚和完整排版。实际分页也可能随文字长度变化，交付前应检查导出稿。

零问题的审查仍有结果导出入口。全部修改提案被驳回时，完成包会注明本轮没有修改，
并保留决定与未解决风险。导出文件中的“未修改”不表示审查已经证明合规或质量达标。

## 保存与退出

草稿会按项目、当前文档和 AI 任务保存。切换任务、项目或界面语言会保留对应输入；
保存失败时可重试或下载草稿。两个页面的保存版本冲突会明确报错，不会静默覆盖较新草稿。
点击退出后，页面先禁止继续编辑，等待草稿保存成功，再关闭本机服务并显示关闭状态。
如保存失败，工作台会保留输入和错误说明；先保存或下载草稿再退出。

## 卸载

运行 `卸载程序.ps1`，按提示输入 `REMOVE`，只删除安装记录登记且校验通过的
程序版本及其快捷方式，保留项目、备份和未登记文件。
自动化环境可显式使用 `-ConfirmRemoval` 跳过文字确认；自定义安装需传入与安装时
相同的 `-InstallRoot`、`-ProjectRoot`、`-ShortcutRoot`。
直接使用便携目录的用户可在关闭程序后删除该程序目录。

当前构建**未做发行者代码签名**。清单与 ZIP 摘要可发现文件不一致，不能认证发布者。
其他设备、远端 CI、特定 WPS 变体和复杂 Word 排版仍需进一步验收。
本机真实 DOC/XLS/PPT 转换、Word 修订、最终回归和发行包证据见
[0.2.3 交付工程记录](release-engineering-0.2.3.md)。当前保留 experimental preview 标识。
