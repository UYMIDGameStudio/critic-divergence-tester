# 0.2.31：让开放审查落实到实际返回模板

综合审查协议允许按文章选择角度，但此前实际导出的返回示例预填结构、方向、方法、
特点四项。这些示例可能形成固定清单的暗示，也重复了四份相同字段。

现在返回模板只展示一个中性的字段形状，明确要求替换角度名称和标识，按照当前
文章的问题、贡献、策略及读者需要选取相关角度。示例的一项不是实际数量要求。
协议继续允许1至10项，通常建议3至6项；不为达到数量或覆盖示例而制造问题。

选角说明进一步要求从文章的承重选择、待解释张力及读者理解或使用结论的障碍
出发，指出保留或调整会改变什么。重要角度不在示例中也可以提出；同一问题的
近义角度应合并。原先四项仍可使用，也可以全部不选。

这项调整减少重复模板文本，不裁剪原文、证据或评价。没有调用模型进行真实稿件
质量评测，不能据此宣称准确率提高、已消除模型偏见或保证节省固定数量的 token。

## 兼容性与验证

本版保持学术协议v4、综评响应v1的字段、状态和数量边界。新选角说明与新请求
一起保存并计算指纹；已经导出的请求、提示词和协议快照不被重写。

回归覆盖实际导出的中性模板、三个不在示例列表中的角度的导入与重载、旧四角度
请求按原快照导入，以及既有引句、数量、类型、重复角度、错误归档与导出约束。
测试中的固定四角度数据保留为历史兼容夹具，与生产模板中的示例数量分开。

发行自检从打包程序实际导出的模板生成合成响应，替换为两个自选角度，再完成
导入和重载；测试使用合成材料，不读取真实稿件或调用外部模型。

安装和升级见 [便携版说明](portable-guide.md)。
