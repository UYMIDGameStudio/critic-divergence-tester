# 0.2.12 · Markdown 表格与代码示例

修复会影响稿件细节的导入错误：转义竖线不再拆成新列，边界空单元格不再丢失，
正文数据行里的横线不再被误删为表头分隔线。分隔线必须全部符合格式且列数匹配，
标题、引用和列表不会被错误吸收到表格中。Markdown 导出会转义单元格内的竖线和
反斜线；回归使用导入、导出、再导入核对列数与单元格内容。

反引号或波浪号围栏中的内容作为带 `fenced_code` 标记的普通文本块保存，包含
围栏本身、缩进、空行和真实换行。示例中的标题、列表和表格不会被提升为正文结构，
也不会决定稿件标题。不同围栏长度、未关闭围栏和原文字符范围均有覆盖。
这种表示沿用已有文本块与审查定位接口，不执行代码。

识别规则参考 [GFM 表格与围栏规范](https://github.github.com/gfm/)。此工具仍不是
完整的 Markdown 渲染器：复杂嵌套或行内语法应对照原件核对。各行列数不同时，
保留全部单元格并给出警告，不采用渲染器可能忽略额外列的行为，以免丢失审查材料。

已保存项目的 IR 与审查回执不自动重写；本修复用于新解析与新导出。产品仍为
experimental preview；内容保持测试不等同于模型审查准确率评测。
