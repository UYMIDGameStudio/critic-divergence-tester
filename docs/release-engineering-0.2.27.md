# 0.2.27：以文稿、证据和批注组织界面

用户提供的设计研究在 2026-09-30 更新至 2.1。新版将视觉身份、真实内容与
整页阅读顺序放在参数之前，并把蓝白灰、等宽网格、圆角卡片降为可选实例。
本次据此重新检查 0.2.26 的工作台，从审查工作的实际材料建立设计方向。

## 从工作内容确定设计

预期使用者是逐段阅读、核对依据、批准修改的作者与审查者。页面中的主角是原文、
引文及判断，不使用与任务无关的产品摄影。采用的识别线索包括：

- **文稿页**：暖纸色、书卷式标题与原文、细页边线。长段正文有独立阅读空间，
  操作与元数据继续使用无衬线字体。所有字体使用本机回退，不要求网络服务。
- **批注**：原文引句和审查意见通过位置链接及页边标记关联。批注装饰不代替
  严重度、核验来源或人工决定；正文和原有标识均保持不变。
- **索引与工具**：项目列表、统计和阶段显示更紧凑；导入表单、原文、判断及
  维护选项按不同职责选择表面、宽度与间隔，不要求共用一个外框。

首页让新稿导入成为主要操作，本机项目为相邻的继续入口。研究入口和维护信息
通过章节分隔落在后续区域。审查页按项目、阶段、模型交换工具、裁决队列、
原文与批注、修订和导出的顺序保持同一阅读身份。专业页扩大原文区域，
论证结构和审查结果呈现为关联栏；窄屏按阅读顺序重新排列。

## 一并修复

0.2.26 的远端单元测试发现，页首将完整 `experimental preview` 标识缩成了
`Preview`。本版恢复完整的实验预览含义，繁中显示「實驗預覽」、英文显示
`experimental preview`，并在浏览器双语检查中验证；未删除原来的测试断言。

## 验证与使用

沿用导入、原文定位、双语、草稿、裁决、修订、复审、备份与恢复的浏览器回归。
布局检查覆盖桌面 1440×1000、390/320×844、200%文字放大、键盘焦点、减少动态、
控件尺寸与实际样式对比度。所有夹具是合成内容，截图和检查报告位于
`dist/ui-style-0.2.27/`；`npm run test:browser` 包含这些检查。

参考资料中的品牌构图是设计方法示例，不直接当作此工具的界面。
截图和自动检查能验证本次样本的排版与操作，不能替代目标作者对效率、
辨识度和长期阅读体验的反馈。本版不改写 IR、审查协议或既有用户项目。

安装、升级与回退见 [便携版说明](portable-guide.md)。
