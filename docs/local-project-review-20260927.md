过严及支持不足集中出现在一份未提供细读记录的旧结果：部分批评把历史阐释和
未来研究命题要求为已经完成的实证／系统综述，把未采用表格或编码本等呈现方式
当作没有论证区分。其他案例则涉及把可能性误读成必然条件，以及忽略已有的限定。
当前学术协议 v2 已要求按研究任务选择标准、核对最强辩护及严重度依据；这批
存档没有 v2 生成的响应，因此本轮不能证明 v2 已消除这些语义问题。

## 从实例落实的改进

- 逐词换行 PDF 的布局恢复、旧项目阅读和搜索，以及预检遮蔽 AI 意见、文书用途
  与标题误判、PDF 跨行否定问题，已在 [0.2.24](release-engineering-0.2.24.md) 修复。
- 同一原件重传会重开旧项目；[0.2.25](release-engineering-0.2.25.md) 增加明确的
  新项目解析入口，实测重新使用当前解析器并保留旧项目全部文件。
- 7 条模型意见自报 `verified`，应用没有独立核实这些外部事实的凭据。0.2.25
  在界面与导出中明确核验来源，修正未来本地规则的错误来源标签。
- 某些 Word 识别记录有脚注存在提示，而初审提示词没有携带。0.2.25 将实际警告
  和质量信号传给审查者，要求区分不可见材料与原稿遗漏。
- 一份旧结果有 2 处引句定位到相邻错误块、1 处改动句末标点。当前内容绑定校验
  对这 3 处均拒绝，严格回显和人工关联均经过同一门槛。未发现这些案例的现行绕过，
  不另加重复校验，也不自动篡改历史引句。该旧结果应在新版中重新审查。

相关重复意见不自动合并或删除；同一修改可能回答多个不同维度的问题。历史意见
中的严重度、事实真伪及人工裁决保持原样。复核建议不等于作者接受修改。

## 限制

全量指本机工作台当前直接项目及其保存的提取正文和模型意见，不包括备份库、
磁盘其他论文或外部网站。外部原始文献、未提取脚注／图片的内容及完整渲染版面
没有被全部重新验证。没有把这些私有文章发送给外部模型重新运行，也未开展作者
试用。新版本经过针对性回归和发行验证；语义准确率及商业试用仍需另行建立证据。
