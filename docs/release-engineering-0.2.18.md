# 0.2.18 · 审查界面中的编号与续文

此前 IR 和导出已保留列表标记，但识别预览、原文侧栏及定位下拉框仍只显示正文，
用户无法直接看到前提编号，按编号搜索也找不到目标。现在这些入口采用一致的展示
文本，包含已提取的编号、嵌套层级缩进及 `續文`／`continued` 提示。定位校正和
范围选择保留原有 block 绑定；UI 提示不写回原文、引文或用户输入。

界面只显示合法且已经记录的标记；旧 IR 未记录编号时不猜测编号。Unicode 十进制
数字（包括全角数字）、常见字母与罗马数字标记均可显示。层级缩进在界面上最多展示
八级，完整层级仍保留在 IR。用户内容按文本转义，字面的 HTML 标签不会作为页面执行。

HTML 静态提取、嵌入对象、图片、嵌套表格、未闭合表格及表格内列表提示补充了
繁體中文与 English。仅精确匹配已知系统提示的完整消息，未登记的诊断保持原样；
正文、文件名和原始证据不经过界面翻译。

真实 Chrome 完成 29 项语言与原文保持检查，包括 HTML 编号搜索、续文标签、
定位选项、HTML 字面文本隔离及八种语言 UTF-16 原稿中的全角编号。另完成完整
导入、草稿恢复、人工裁决、逐段批准、修订、Word 下载、备份和恢复流程；
28 项界面状态与交付回归通过。实际识别预览截图已检查。

产品仍为 experimental preview，测试结果不代表模型审查准确率或商业试用已通过。
