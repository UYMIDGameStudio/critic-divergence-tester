# 0.2.21 学术协议交付与审查改进

学术审查协议 v2 从源码更新进入 wheel 与本机 Windows 便携交付。它把代表性论文、
原始指南和权威写作标准提炼为有条件的审查要求：先还原主张与贡献，再核对关键
推理、适用方法、最强异议、引用和结论边界。完整来源与适用范围见
[学术质量框架](academic-quality-framework.md)。

每次独立审查只包含所属维度的 3–5 项具体标准，不把完整阅读笔记重复放入请求。
旧请求、对抗深审与复审继续保留原始协议快照；本地字面预检也没有升级为语义
审查，不会因字段齐全而宣布稿件正确或模型准确。

便携版根目录的使用说明按实际文档链接重定位，新增指南不再依赖手工维护的
文件名名单。原始指南、正文、外部链接及片段定位保持各自含义。

审查页的原文搜索曾导致证据链接跳转后仍看不到原文：目标段落被筛选隐藏，
浏览器只更新锚点。本版本在点击或键盘激活证据链接时，清除冲突的原文筛选，
展开并显示目标段落，将键盘焦点移至原文，同时保留浏览器锚点导航。原始文本
不变。繁體中文与 English 的浏览器验证检查实际可见区域、焦点和重复跳转，
不再只核对链接地址和元素存在。

安装包自检新增学术协议检查：在独立临时项目中生成三个维度的真实请求，核对
协议版本、按理论/人文任务选择的条目、来源和持久化快照。这不调用模型，也
不生成虚假的语义审查成绩。

交付前验证：37 项学术协议、安装运行、wheel、便携构建和指南链接回归通过；
细读页面的繁中/英文证据跳转验证通过，现有对抗深审浏览器流程的 13 项检查也通过，
两组浏览器验证均无脚本异常或外部请求。真实冻结程序与隔离安装的自检结果保留
在本机发行目录的验证记录中。

本版本仍为 experimental preview。协议与工作流的自动检查只能证明软件行为，
不能替代真实作者试用或模型批评的独立质量评估。
