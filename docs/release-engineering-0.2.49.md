# 0.2.49：Word 链接文字与修订保留

原先修改含超链接的段落时，一律拒绝原位编辑并回退规范化 Word 副本，即使改动只发生在
链接周围的普通文字。合成文件已复现该问题。

现在将段落按普通文字和各个 `w:hyperlink` 分别映射。支持修改周围文字、链接标签和各自
格式化的多个 run，保留链接属性、目标关系、段落属性与未修改部件。正文、表格单元格和
脚注/尾注共用这一逻辑。净稿与修订稿来自同一已批准文字，修订标记在原有归属内生成。

独立插入链接边界的文字默认是普通文字；当标签内部修改被字符差异拆成短匹配和连续词尾
时，词尾仍保留在正在修改的链接中，避免只链接新词的一部分。导出说明明确提示该规则，
需要核对最终可点击文字。修改文字不改写目标地址，也不构成文献内容核实。

纯删除不为新文字分配链接，可跨原有范围。带新文字的替换如果跨越不同链接归属、或跨越
含链接的单元格段落，则拒绝猜测归属。含链接的段落拆分、域、书签、嵌套链接及其他复杂
内联内容继续提示人工核对；现有修订、注释引用和来源绑定保护继续独立执行。
重复文字若允许多个等价修改位置，且这些位置归属不同链接或普通文字，也会拒绝猜测。
例如两项相同引文标签指向不同来源，不能仅凭最终文字决定删除了哪一个。

链接和普通文字的映射使用有序范围查找；字符比较沿用原有变更中段预算，不对长段落进行
无界精细比较。注释标记的1024上限按整个段落执行，不会因分组而放宽。
重复文字的等价定位检查单独限制为每段12000步，超过预算时明确要求核对。

专项检查覆盖标签与周围文字、边界插入、删除与混合范围、八种语言、多样式、表格与注释、
大量未修改链接、段落拆分与原有保护。独立 XML 遍历核对修订接受后等于净稿、拒绝后等于
原文，并比较格式及目标关系。真实浏览器通过人工操作确认、提案批准到净稿和修订文件
导出全程，原件逐字节不变。发行自检新增 `word-hyperlink-edits`，共40项。

## 真实 Word 验证的限制

本机 Word 直接自动化启动超时，独立启动后也无法取得可确认进程归属的自动化对象。
验证工具因此停止，没有连接或操作已有文档；未生成通过结果，不能将 XML 检查冒充
Word 客户端打开、接受/拒绝或视觉版式检查。本轮不声称完成这些实机验收。

可选重现工具为 `scripts/verify_word_hyperlinks.py` 与同名 PowerShell 文件，只生成和读取
仓库 `dist` 内的合成文件，并限制连接到本次拥有的空实例。原始失败日志保存在本机
`dist/native-word-hyperlinks.49.log`，独立启动诊断在 `dist/native-word-hyperlinks.prelaunch.49.log`。

参考 [Microsoft Open XML Hyperlink](https://learn.microsoft.com/en-us/dotnet/api/documentformat.openxml.wordprocessing.hyperlink?view=openxml-3.0.1)
的子元素与关系定义；此参考不替代真实 Word 客户端验收。
